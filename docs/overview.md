# Project overview

## Context

STI-NEM is a collaborative academic project for an AI-assisted tutor aligned with the New Mexican School framework. It is described by the project owner as a master’s thesis project at Tecnológico Nacional de México, focused on primary-school learning.

## Contribution boundary

The project owner’s contribution was frontend development, particularly the teacher module. The showcase therefore describes teacher-facing workflows and does not claim responsibility for the complete tutor, student or administrator experiences, backend services, or AI models.

## Evidence included

The approved screenshot shows a teacher-facing exercise criteria form with an empty output state. It supports a claim about interface work, but not a claim that AI-generated exercises were successfully produced. The group-screen capture was excluded because it displayed an account name.

## Verification limits

The supplied architecture document describes the frontend design and a possible service boundary. The implementation repositories were unavailable for direct inspection, so source behavior, exact dependency versions, and service integrations remain unverified.
